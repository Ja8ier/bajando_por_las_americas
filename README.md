<h1 align="center">Bajando por las americas</h1>

Pasos para ejecutar el juego según tu sistema operativo:

<div style="display: flex; gap: 20px;">
  <div style="flex: 1; border-right: 2px solid #333; padding-right: 20px;">
    <strong>WINDOWS:</strong><br>
    Instalación de LOVE2D:
      Paso 1: Ingresar a la página de LOVE2D y descargar el archivo .ZIP o instalador según tu sistema operativo https://www.love2d.org/
      Paso 2:
        Si descargaste el .ZIP: extraerlo y mover la carpeta a la ruta que prefieras.
        Si descargaste el instalador: ejecutarlo y seguir las instrucciones de instalación.
      Paso 3: Copiar la ruta del directorio donde se instaló LOVE2D.
      Paso 4: Presionar la combinación de teclas WINDOWS + R, se abrirá la ventana de ejecutar.
      Paso 5: En la ventana ejecuar pegar el siguiente comando: SystemPropertiesAdvanced. Presionar enter.
      Paso 6: Click en variables de entorno. Se desplegarán las variables de entorno.
      Paso 7: En el apartado de Variables de entorno para usuarios seleccionar la variable PATH y click en editar.
      Paso 8: Click en nuevo y pegar la ruta que habiamos copiado previamente. Click en aceptar.
    
    Ejecución del juego: Abrir el cmd y acceder al directorio donde está el repositorio, y ejecutar el siguiente comando: love .
